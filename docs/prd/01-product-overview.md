# 产品概览

## 产品名称

- **中文：** 相亲表
- **英文：** MatchTable

## 产品定位

MatchTable 是以标准化个人资料为核心的结构化相亲平台。

用户创建自己的 **MatchTable**（相亲表），展示个人信息与择偶要求。

其他用户可以浏览、收藏并发起牵线请求。

平台**不提供**即时聊天。

联系方式仅在**双方同意**后才可见。

## 产品目标

MatchTable 针对传统相亲产品中的常见问题：

- 信息不透明
- 资料不完整
- 筛选效率低
- 沟通成本高
- 无效匹配过多

通过 MatchTable 格式标准化资料，提升相亲匹配效率。

## MVP 范围

### 纳入

- 用户注册与登录
- MatchTable 创建
- MatchTable 编辑
- 照片上传
- 浏览发现广场
- 搜索与筛选
- 资料对比（多表横向对照，可固定自己的相亲表）
- 收藏
- 牵线请求
- 联系方式交换
- Dashboard 管理后台
