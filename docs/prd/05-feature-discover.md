# 模块 5：资料对比

用户可将多份相亲表放在同一张对比表格中横向对照，快速比较关键条件。

## 入口

- 发现广场 / 用户详情页 — **加入对比**
- 收藏列表 — 多选后 **开始对比**
- 对比页 — 直接访问 `/compare`（需登录）

## 对比人数

- 最少 **2** 份资料（含可选的「我的相亲表」）
- 最多 **4** 份资料（MVP）

## 表格结构

参考传统相亲资料对照表布局：

| 列 | 说明 |
|----|------|
| **第 1 列（对比项）** | 固定行标签，如年龄、身高体重、学历、城市等；横向滚动时始终可见（`position: sticky`） |
| **第 2 列起（资料列）** | 每列对应一份相亲表；表头为昵称 + 主图缩略图 |

行标签与 MatchTable 字段映射：

| 对比项 | 数据来源 |
|--------|----------|
| 年龄 | `birthday` 计算 |
| 身高 / 体重 | `height`、`weight` |
| 学历 / 学校 | `education`、`school` |
| 城市 | `city` |
| 职业 / 年收入 | `occupation`、`income` |
| 房 / 车 | `house`、`car` |
| 婚姻状况 | `marital_status` |
| 是否接受异地 | `accept_ldr` |
| 爱好 | `hobbies` |
| 自我介绍 | `bio` |
| 择偶要求 | `requirements` |

联系方式**不参与**对比（隐私字段，仅在双方接受牵线后可见）。

## 固定「我的相亲表」

注册用户可开启 **固定我的信息**：

- 开启后，当前用户的相亲表作为**第一列资料列**插入表格
- 该列在横向滚动时与对比项列一起 **sticky 固定**，便于对照其他候选人
- 若用户尚未创建相亲表，显示引导入口（跳转 `profile/create`）
- 偏好存储在客户端（localStorage），无需新增数据库表

## 交互

- 从对比表移除某一列资料
- 空字段统一显示 `—`，保持行对齐
- 长文本（bio、requirements）单元格内截断，点击展开全文
- 每列资料列底部快捷操作：查看详情、收藏、发起牵线请求

## 权限

| 角色 | 能力 |
|------|------|
| 游客 | 不可使用对比功能 |
| 注册用户 | 完整对比能力 |
| 管理员 | 同注册用户 |

## SSR 要求

- **发现广场与用户详情页** 必须使用 SSR — 见 [10-architecture.md](./10-architecture.md#ssr)
- **资料对比页** 为登录后功能，无需 SSR；对比项列与资料列须支持移动端横向滚动
